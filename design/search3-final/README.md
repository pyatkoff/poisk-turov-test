# AnyTour Search3 — Final Design

Эта папка — канонический набор утверждённых макетов нового Search3.

Порядок макетов:

1. `01-search-interface.png` — интерфейс поиска туров.
2. `02-search-filters.png` — фильтры поиска.
3. `03-flight-selection.png` — выбор рейсов, desktop + mobile.
4. `04-tour-final-review.png` — итог тура, desktop + mobile.
5. `05-booking-page.png` — страница бронирования тура.
6. `06-lead-ui-kit.png` — UI-kit заявки на тур и lifecycle заявки.
7. `07-footer-spec.png` — спецификация футера, desktop + mobile.
8. `08-mobile-booking-flow.png` — цельный mobile flow бронирования и общения.

## Правило

Эти 8 файлов являются утверждённым визуальным baseline для Search3. Черновики и старые версии сюда не добавляются.

Текущая реализация находится в `v2/`, рабочая карта — `v2/SEARCH3_WORK_MAP.md`.

Production не должен выкатываться только на основании зелёного функционального QA: перед production требуется визуальная приёмка по этим восьми макетам.
