# AnyTour Design System 1.0

The canonical AnyTour design-system generation is **1.0** for the current owner-directed site-wide visual unification phase.

Repository roadmap, policy and CI assertions must follow the active owner direction in `OWNER_PRIORITY.json` rather than hard-code a superseded design-system generation. The current goal is one coherent public product across homepage, destination/editorial pages, search, results, selected tour and lead surfaces.

This declaration does not rename implementation files whose `-v1` / `-v2` suffixes are independent code/module generation identifiers. Those filenames may change only through a dependency-mapped technical migration.

Do not add a dedicated GitHub Actions workflow solely to police this version label; keep consistency checks inside existing cheap policy/owner guards when needed.
