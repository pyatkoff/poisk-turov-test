# AnyTour Design System 2.0

The canonical AnyTour design-system generation is **2.0**.

Repository documentation, comments and CI assertions must use Design System 2.0 terminology. Legacy design-system generation labels are not valid current terminology and are rejected by `scripts/ci/validate_design_system_version.py`.

This version declaration does not rename implementation files whose `-v1` suffix is an independent code/module generation identifier; those filenames may only change through the dependency-mapped technical refactor.
