## С чего продолжаем

1. SEARCH: выполнить ближайший пакет OTA-выдачи из fresh `current_task` и
   [product plan](../search3-product-development-plan.md). Entities/keyboard приёмка
   завершены; source/search/offer identity развивается отдельно через текущие INT claims.
2. INT: довести canonical P2 storage/auth в границах допуска; официальный контракт
   Андромеды собирать независимо. Не повторять старые supplier/content/matching batches.
3. SITE: точные переходы и правдивый путь выбора; SEO: использовать уже собранную
   матрицу типов страниц для brief одного полезного шаблона, не повторять её сбор.
4. Готовые ANEX части переносить ограниченными пакетами на свежую release, с одним
   UI-владельцем; user review проводится уже на едином тестовом сайте.

Дата/ветки сверки: release `cf3f4b6fc0a1b82b7e6b4f3e3ae6818c5d198c90`,
ANEX `4fa42a3907623a0673a42148981d3e5a0f9c9233`.
Это исходные pins плана, а не будущий source для runtime/deploy. Перед исполнением
проверять свежий head, claims, CI и actual published state. Подробные планы сами
не меняют применимые gates или production-допуски; исполнение задаёт fresh current_task.

Дополнение 2026-09-09 по поручению «догнать ведущие ОТА»: выдача → выбранные условия →
короткий список/сравнение → цельный мобильный путь → доверие на страницах → готовые
поставщики → измеримый пользовательский рубеж. Точные ID/приёмка в product plan;
все пункты не запускаются одновременно. Полный цикл оплаты/брони — отдельная бизнес-фаза.

## Статусы

У пакета есть `ready / in_progress / blocked / done`; дополнительно отмечается,
что реализовано, проверено, опубликовано в preview и отдельно принято для production.
Начальное «готов к планированию» не означает, что отсутствующая интеграция или панель
уже работает. Точные acceptance и зависимости описаны в профильных файлах.

Сроки не назначены наугад. После первого связного пакета каждого направления оценить
остаток по фактическому темпу и внешним входам. Контракт Андромеды, реальный owner auth
и production approval — явные зависимости, остальные работы их не ждут.
