## Preview and explicit operation

Existing endpoint: `/_preview/search3-anex-candidate/api-anex-search3-preview.php`.
The handoff branch runs before PDO/provider initialization. `GET ?action=handoff_token` requires the
existing ANEX session and returns its CSRF token. Handoff POSTs require JSON, the exact same production
Origin/Host, `Sec-Fetch-Site:same-origin` and that session token. Replies are private/no-store/no-referrer/noindex.

| Action | Exact fields besides action |
| --- | --- |
| `handoff_freeze` | generation, search_ref, offer_ref, local_hotel_id, choice_ref, csrf |
| `handoff_create` | operation_id, csrf |
| `handoff_status` | operation_id, csrf |
| `handoff_revoke` | operation_id, csrf |

The canonical observation is returned for review before explicit create. No native message is sent by
freeze/create/open. Equal canonical record/selector reuses the original operation, regardless of JSON
key order. Intent metadata/bytes/hash stay in the same PHP session across serialization. At most8 wire
operations are retained per session;429 never silently evicts an issued/UNKNOWN operation.

Create is durably checkpointed UNKNOWN before its only HTTP attempt. Further create clicks use
signed status, never create again. Timeout/missing does not replay UNKNOWN. Prepared status/revoke
are local; issued revocation is signed, and lost revoke never exposes ready links. Changed generation
or stale selected record blocks a new create, while issued status/revoke remain available in the same
session. Original wire bytes, hash and producer key ID remain unchanged. Key rotation cannot change
the key for an already issued intent. None of these operations alters native likes or sends to a tourist.
