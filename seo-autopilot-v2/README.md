# AnyTour SEO Autopilot 2.0

Dedicated SEO control plane for anytoour.ru.

## Mission
Grow qualified organic traffic and SEO landing-page coverage without destabilizing tour search, lead flow, pricing, analytics, or Design System 2.0.

## Operating loop
1. Inventory current indexable surfaces.
2. Detect technical/content/architecture defects.
3. Prioritize by organic impact and risk.
4. Apply only narrow SAFE changes autonomously.
5. Verify indexability and page contracts.
6. Record outcome and select the next slice.

## Initial lanes
- SEO_INVENTORY
- INDEXABILITY_CANONICAL
- SITEMAP_ROBOTS
- META_H1_CONTRACT
- DUPLICATION_CANNIBALIZATION
- LANDING_ARCHITECTURE
- INTERNAL_LINKING
- OFFER_PRICE_DATA
- STRUCTURED_DATA
- CONTENT_QUALITY
- SEO_MONITORING

## Protected boundaries
SEO Autopilot must not change Tourvisor/search behavior, pricing logic, lead persistence/transport, Yandex Metrika goals/counter behavior, or unrelated product UX unless an approved SEO task explicitly requires it.

Design work must use AnyTour Design System 2.0 only.

## Release policy
Prefer small auditable PRs. SAFE technical/content contract fixes may proceed autonomously. MEDIUM/HIGH changes that alter URL architecture, mass-create pages, change canonical strategy, redirect large URL sets, or affect protected boundaries require an explicit plan/evidence gate before release.
