# SEO2 task model

Tasks are independent SEO lanes with explicit risk, evidence and completion contracts.

Priority is impact-first:
1. accidental deindexation/canonical/domain duplication
2. crawl/sitemap/indexability defects
3. wrong or duplicated intent metadata
4. architecture/cannibalization
5. internal linking
6. factual commercial enrichment
7. structured data/content quality
8. monitoring and opportunity expansion

SAFE tasks can produce narrow autonomous PRs. MEDIUM/HIGH tasks require a recorded plan/evidence gate before release.
