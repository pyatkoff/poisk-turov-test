# SEO Autopilot 2.0 Roadmap

## P0 — Control and safety
- SEO_INVENTORY
- INDEXABILITY_CANONICAL
- SITEMAP_ROBOTS
- META_H1_CONTRACT
- legacy-domain and duplicate URL cleanup

## P1 — Architecture
- semantic/intention map
- country landing family
- resort landing family
- hotel landing family
- useful thematic landing families only where distinct search intent exists
- canonical rules for filters and parameters
- breadcrumbs and internal-link graph

## P2 — Factual commercial enrichment
- reusable live offer/price snapshots
- freshness and stale-data rules
- factual hotel/resort attributes
- schema.org based only on rendered factual content

## P3 — Content quality
- unique intent-first introductions and supporting blocks
- FAQ only where useful and factual
- thin/duplicate/cannibalizing page detection
- template quality scoring

## P4 — Monitoring and autonomous improvement
- indexability regression checks
- sitemap/canonical/title/H1 checks
- broken internal-link checks
- stale factual-data checks
- SEO opportunity queue
- before/after outcome recording

## Success principle
Optimize for qualified organic traffic and useful landing coverage, not raw indexed-page count.
